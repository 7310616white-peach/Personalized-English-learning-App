# 1.1.3 历史题包与重复导入修复

## 修复结果

- 四级任务与顶部安排统一读取所选v3题包的daily.cet，保留顺序和任务引用。
- 无daily的v3用题包日期回退，v1/v2保留其支持的选择题入口。三日轮换锚点仍是2026-10-22。
- 真实手机日期与题包任务日期分开；历史包显示补做提示，回到前台刷新真实日期。
- 词汇、阅读、选词/匹配、翻译与包内听力的完成状态按题包和题目/听力组身份关联实际提交，跨午夜不清零。
- 当前到期复习与新词实际当天10＋2额度仍按真实时间；已学词不再当新词。其他题包的学习不会冒领本包完成。
- 包内听力轮换固定到题包日期；来自其他包的补充校考训练仍按实际当天记录。音轨身份、校考优先和绑定存储保持原样。
- 错题本始终显示拓展入口，可筛选不同日期题包。学习台能直接打开daily.cet引用的未完成拓展题。
- 相同内容重复导入返回已有题包并提供“继续学习此题包”。对象字段顺序与JSON排版不影响判同，协议默认值先规范化；数组顺序和实际内容变化会报冲突。
- 文件选择、粘贴、Android分享确认使用同一幂等导入逻辑。新建与判重在原事务中完成，不自动改ID或复制词汇。

## 验证范围

本地核心测试56项、原有手机尺寸流程17项、正式模式6项界面测试全部通过；生产构建与格式检查通过。
覆盖23日补22日、22/23日切包、24日三项安排、无错题拓展入口、判同与冲突、草稿和释义弹窗。

核心回归使用8段原创合成WAV，比较全部备份记录、绑定及音频字节；同时保留词汇/听力复习和草稿。未读取手机中的个人音频或学习库，因此不把合成测试当成对个人8段文件的现场验收。

手机界面测试采用Pixel 7尺寸Chromium。当前开发机没有Android SDK/ADB及可连接真机，Nothing原生边缘返回、文件分享、安装时的数据保留仍需真机确认。Android编译和签名验证与浏览器测试分别记录，不能互相替代。

## 安全升级

1. 在旧App“我的”导出完整备份；有音频时使用含音频ZIP，确认实际文件已保存在App之外。
2. 安装使用相同applicationId和原正式签名的1.1.3（versionCode 11），直接覆盖1.1.1/1.1.2正式版，不先卸载或清数据。
3. 首次打开选择22日题包，核对已交阅读与待交选词；到错题本打开拓展练习，再核对听力8段绑定及历史记录。
4. 如果提示签名不兼容，停止安装并保留旧App，先核对是否仍为早期debug测试包。不要通过卸载来跳过备份。

本次源码不会读取、重命名或清空个人学习数据库。完整备份恢复仅由用户主动选择并确认；重导学习题包不走备份替换流程。
