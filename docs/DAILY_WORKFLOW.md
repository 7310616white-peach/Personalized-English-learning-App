# 每日六项流程

正式界面隐藏示例入口，Android使用固定私人签名；发布方式见[发布说明](RELEASE.md)。

## 学习台

| 顺序 | 每日任务                        | 完成依据                                                       |
| ---- | ------------------------------- | -------------------------------------------------------------- |
| 01   | 今日词汇，10个四级词＋2个科研词 | 先过词义，再成功提交当天新词拼写；不是必须全对                 |
| 02   | 间隔复习                        | 原有词汇/阅读、听力、选词/匹配的到期任务均已保存；无到期可跳过 |
| 03   | 听力训练，每天保留              | 所选音轨整组提交；真实校考材料优先于四级及内置演示             |
| 04   | 四级习题每日练                  | 当天安排的两项阅读均提交，第三天还需提交段落翻译               |
| 05   | 每日文献阅读练                  | 该段科研英文的理解题均已提交                                   |
| 06   | 每日翻译一句                    | 一句译文保存为待批改，非自动准确评分                           |

范文栏单独阅读，不安排每日作文。用户主动提出写作时仍可用原有写作题型。
开始按钮和有色卡片推荐下一项未处理任务；其他已准备任务可主动提前打开，不强制锁住顺序。
同一题包内已提交的词汇、阅读、拓展题和听力不会因跨午夜重置；草稿、只播放音频、打开页面或失败的写入均不算完成。未答客观题提交后计错，但仍是一次已完成的练习。
无材料明确显示待补充，不把缺题或缺音频标成已完成。
02没有到期内容时自动跳过，计入已处理的流程，不新增虚构复习记录。

今日词汇先逐词看中英文释义、搭配、例句与辨析，点击“看过了，下一个词”保存进度。
支持回看；保存退出后从第一个未确认的词继续。过完本组再点击“开始拼写”。
仅看释义不计新学、不计答题次数，也不提前安排复习；拼写提交后才计入今日完成。
复习与错题再练直接答题，不强制重看词义。

## 阅读搭配

以手机当地日期、2026-10-22为第0天，每三个自然日循环：

| 日期示例     | 阅读三选二         | 段落翻译   |
| ------------ | ------------------ | ---------- |
| 10-22、10-25 | 仔细阅读＋选词填空 | 不安排     |
| 10-23、10-26 | 信息匹配＋仔细阅读 | 不安排     |
| 10-24、10-27 | 选词填空＋信息匹配 | 每三天一次 |

每天的单句翻译单独保留。日常不自动安排作文。
App与复制给每日英语的提示词使用同一日期规则，长期开着App跨午夜后复制也会重新取当天日期。
选择历史题包时，四级安排以该包daily.cet的顺序和引用为准；无daily的v3按题包日期回退，v1/v2只显示它们支持的选择题。
当前真实日期与题包任务日期分开显示，补做不改写原始作答时间；间隔复习始终按真实当前时间到期。
阅读/翻译完成按题包和题目ID关联全部实际提交；词汇新学只收录本包尚未作答的词，实际当天10＋2限额仍跨包计算。
题包内听力选择沿用校考优先并固定到题包日期，完成关联packId与setId；来自其他包的补充训练仍按实际当天记录。
不完整题包明确显示待补充。不会因换日期自动补入该包没有安排的题型。

相同ID的完全相同内容（忽略JSON对象字段顺序、文件排版，应用协议默认值）重导不写库，提供直接切换继续学习。
同ID不同内容明确报冲突，既不覆盖也不自动改ID。当前版本不提供内容替换；更新已用题包需要单独设计有引用映射和回滚验证的迁移。
错题本的拓展练习入口始终显示，可筛选不同日期题包，与是否已有错题或待批改记录无关。

## 我的与范文

底部顺序：词汇手册、听力训练、学习台、错题本、我的。
“我的”保留原来的全部题包导入、结果导出、备份和恢复，加入学习统计与手机提示词。
“每一次练习，都有迹可循”已从学习台移至我的。
学习台的独立范文入口收录每日题包范文，以及已提交作文练习的参考；未提交作文的参考不会提前收进范文栏。

## 给每日英语的提示词

在“我的”展开“手机使用流程与每日英语提示词”：

1. 复制首次设置提示词，发给手机ChatGPT“每日英语”。
2. 每天复制每日学习提示词，含实际日期和今天的两项阅读/段落翻译安排。
3. 下载JSON附件，回到“我的”选择文件，或使用分享/粘贴导入。
4. 做完导出答题文本/JSON，发回每日英语批改。另存完整备份。

听力只需首次导入材料清单和原WAV；之后把“听力索引”给每日英语，按稳定ID引用。
没有真实音轨时必须补充，App不会联网生成音频、臆造校考答案或请求付费AI。
科研原文可以来自用户提供的文献；若用原创练习段落，必须明确标注模拟，不能伪造论文或DOI。

## v3 的可选 daily 扩展

保持原数据库名称、表结构和备份v3；旧v1/v2/v3题包与备份继续可读。
新每日包使用schemaVersion=3，在已有words/choices/listening/written/glossary上加daily。

```json
{
  "cet": [
    { "type": "choice", "choiceIds": ["cet01", "cet02"] },
    { "type": "word-bank", "taskId": "bank01" }
  ],
  "researchChoiceIds": ["research01", "research02"],
  "sentenceTaskId": "sentence01",
  "modelEssays": [
    {
      "id": "essay01",
      "title": "范文标题",
      "topic": "英文主题",
      "body": "英文范文全文",
      "notes": "中文结构和表达说明",
      "source": "原创或来源说明"
    }
  ]
}
```

这里是daily对象示意，不是完整可导入题包。所有引用必须对应本包真实题目。
仔细阅读和文献题分别放choices，不可共用同一题；文献题必须有passage。
选词、匹配、段落翻译和每日一句继续使用已有written类型，段落翻译与每日一句不可共用同一个任务。
范文随题包存储和备份，不增加另一份数据库。新daily扩展需要本候选版或更新版本读取。
完整原创示例：[daily-preview.json](../public/examples/daily-preview.json)。

## 电脑验收

预览使用独立端口4174，与原4173的浏览器存储分开。只在预览中导入原创样本，不清理原有个人记录。
检查六项顺序、开始按钮顺延、三天安排、范文与我的、手机尺寸和题后查词。
用户确认后再移除演示入口，整理固定签名、真实日包和Android真机验收，随后决定发布1.0。
