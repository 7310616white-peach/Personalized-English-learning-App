# 1.0 候选版代码自查

本轮为实现者自查，不冒充独立第三方审阅。范围是每日流程、UI重组、图标和原有存储边界。

## 已整理与修正

- App只组装导航与练习状态；文件接收、系统返回、外部选词拆到usePlatformInbox。
- StudyActivity使用明确的区分联合，StudySessionView复用已有拼写、听力、拓展组件；没有第二套答题引擎。
- 每日日期规则、完成判断、听力优先级放纯domain函数；卡片组件只展示和触发操作。
- 任务完成从已提交记录计算，不用按钮点击、本地布尔标记或草稿伪装完成，不新增易失配的每日完成表。
- 元数据引用、文献原文和单句/段落翻译边界在导入前校验，题包和范文沿用现有备份。
- 修正拼写/单选和听力幂等分支：相同提交ID、不同作答会被拒绝，避免页面作答与已存结果不一致。
- 真实校考优先，内置模拟库不冒充校考覆盖真实CET任务；缺WAV明确提示。
- 主观翻译保持待批改，不按范文相似度给出假分数。UI文案统一为“我的”，内部稳定路由和数据库ID不改名。
- Android构建改为手动触发，防止本轮仓库更新自动生成未验收的APK。

## 验证

46项核心测试和16项手机尺寸浏览器流程通过，TypeScript/生产构建和格式检查通过。
覆盖三选二/三日翻译、六项依次推进、客观题两项都完成、跨刷新恢复、旧包/备份兼容、
每日元数据与范文恢复、写入失败不离页、题前不泄露答案、每日提示词跨日期更新。
测试使用独立虚构数据，不读取个人学习库。Android图标XML可解析；本轮不编译APK，不宣称Nothing真机通过。

## 留下的边界

- 三种答题Hook的串行草稿保存仍有相似代码。当前每种输入有不同事务与播放状态，暂不引入通用状态框架；后续若继续加题型，再依据共同约束提取。
- 个人小数据量下用完整本地记录计算每日状态；本轮未做大规模性能压测。数据明显增大时应先测量再加索引聚合。
- 手机端系统返回、软键盘、分享和WAV长时间播放仍需Nothing真机验收。
- 正式APK前需固定私人签名并保管密钥，不把每次随机debug签名的体验包当可持续升级的正式版。
- 示例入口和原创预览库保留到用户确认。移除入口不等于清空数据库，不自动删除既有学习记录。

目前未发现阻止电脑预览的结构或存储问题；这不等于永久没有缺陷，也不等于已满足正式Android发布条件。
