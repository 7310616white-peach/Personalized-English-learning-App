# 手机使用：每日英语 → 拾词

## 每天只做四步

1. 在拾词“题包与数据 → 手机使用流程与每日英语提示词”复制首次设置提示词，发到手机 ChatGPT 的“每日英语”。只需设置一次。
2. 每天复制简短的“每日学习提示词”，让每日英语给一个可下载的 `daily-YYYYMMDD.json`。
3. 下载后，回拾词“题包与数据 → 选择题包 JSON”导入。也可从文件管理器的“分享 / 打开方式”选择拾词，核对后点击“确认导入”。
4. 做完题，在“题包与数据”导出答题文本或 JSON，再发送给每日英语批改。完整备份另存到 App 外，答题结果不能代替备份。

ChatGPT 若无法创建真实附件，可以输出纯 JSON。长按复制后使用拾词的“粘贴题包 JSON”，不要连同代码围栏或聊天说明粘贴。
首次设置提示词也能从 App 导出成 TXT，作为附件发给每日英语，不需要手机能看到 Codex 对话。

## 校内听力：音频只导一次

准备 `library.json` 和原始 WAV。让每日英语根据你实际上传的文件名生成材料清单，原文件名不要改。

| 文件                | 在哪里导入                              | 用途                                    |
| ------------------- | --------------------------------------- | --------------------------------------- |
| library.json        | 听力训练列表最下方“导入 / 补绑听力材料” | 定义每个 Unit、音轨和预期文件名         |
| WAV，可一次多选     | 同一个“导入 / 补绑听力材料”栏           | 保存离线录音，与清单中的 audioFile 对应 |
| daily-YYYYMMDD.json | 题包与数据                              | 今日词汇、阅读与引用这些音轨的听力题    |

导入清单与 WAV 后，核对音轨名称、预期文件名和已选择文件，再确认保存。
文件名唯一且相同时自动对应，其他情况可在下拉框手动选择。显示“待补绑”的音轨暂不能练习。
保存后的录音已复制进本机，日常学习不依赖下载目录中的原位置；仍应另存原 WAV 备份。
同一音轨 ID 不能换成别的录音，材料内容有变化请用新材料库 ID。

然后在“题包与数据”导出“听力索引给 ChatGPT”，发送给每日英语。
索引包含可引用的 libraryId、trackId、文件名及原题定义，不包含 WAV 和个人答题记录。
每天的新 JSON 只需使用相同音轨 ID，不必重新导入音频。没有可用音频时请让每日英语使用 listening=[]。

PPT 没有标准答案：原题 grading.status=missing，只记答案，不自动判错。
AI 推断的参考答案用 draft，未核对原文用 draft 或 missing，不能冒充学校答案或真实录音原文。

## 手机操作

- 今日词汇先点“开始学习”，逐词看中文释义、搭配和例句；过完这一组再点“开始拼写”。中途退出自动保留已看进度，复习与错题仍直接答题。

- 练习页面任意非控件区域左右横滑都暂存退出；纵向滚动不退出。输入框、播放器、倍速选择器等控件保留自己的手势。
- Android 左右边缘向内返回使用 AndroidX 返回分发；提交或草稿写入未完成时不越过保存边界。Nothing OS 实际动画与手势识别仍需对应手机验收。
- 阅读题提交前不能点词查义；提交后在原文、题干和选项中点英文词，弹出本地释义。听力提交后的原文同样支持。
- 题包可带可选 glossary 语境释义，供离线查询，不额外计入每日 12 个新词。未收录的词如实提示，可主动打开在线词典核对。
- 收藏词仍保存在词汇手册，已移除独立的“阅读查词”页面。外部阅读软件若支持 Android 选中文字菜单，可选“拾词查词”打开释义浮层；它无法替其他阅读器全局接管单击行为。

## “在 ChatGPT 中用拾词打开”的范围

拾词实现了 Android ACTION_SEND 与 ACTION_VIEW 的本地 JSON/文本接收，先校验、预览再确认，不自动下载聊天中的链接，也不自动恢复备份。
来源 App 是否提供分享文件或“打开方式”，以及文件 MIME 类型是否匹配，由来源 App 和系统决定，不能通过拾词代码强制添加 ChatGPT 菜单。
官方 OpenAI 文件文档没有保证某一版 Android ChatGPT 的附件菜单一定出现第三方 App；因此文件选择与粘贴入口始终保留。

参考：[OpenAI 文件工作流](https://learn.chatgpt.com/docs/artifacts-viewer)、[Android 接收分享](https://developer.android.com/develop/ui/compose/sharing/receive)、[Android 返回手势](https://developer.android.com/guide/navigation/custom-back/predictive-back-gesture)。

## 安装与升级

先在旧版本导出完整备份，并确认文件在 App 之外，且有听力时备份包含音频。
1.0起使用固定私人发布签名，后续正式版保留包名并递增版本号，可覆盖更新。
此前debug测试包签名不兼容，先保留旧安装并导出完整外部备份，不要直接卸载或清理数据。
Nothing 真机、分享文件权限、外部阅读器选词、系统返回与升级保留记录都列入真机验收。
