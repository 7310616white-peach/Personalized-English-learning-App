浏览器测试使用 Playwright 的 Pixel 7 尺寸 Chromium，使用原生 File API 和下载事件验证：

- 导入示例、重复导入拒绝。
- 草稿跨刷新恢复、回车答题、连续练习、错题与选择题。
- 导出结果与完整备份，在全新浏览器上下文恢复。
- 首次资源缓存完成后的断网重开与作答。


测试服务只监听 127.0.0.1:4175。自动测试没有访问真实个人学习数据。
浏览器测试生成的截图和失败追踪用于审阅，不代表实际 Android 设备测试。

## Android 真机验收

本机尚无 Android SDK；原生编译通过 GitHub Actions 执行，以对应运行的实际结果为准。
安装符合 Capacitor 8 要求的 Android Studio/SDK 后，先执行 `pnpm android:sync`。

1. 全新安装后无账户和学习记录，主动导入 JSON。
2. 在系统英文键盘与常用第三方键盘中，检查自动纠错关闭、回车提交、连续输入和键盘遮挡。
3. 输入一半后切后台、系统回收进程、重新进入，确认已成功保存的草稿恢复。
4. 答错与答对各一次，关闭重开后核对错题次数、原始答案和复习日期。
5. 飞行模式冷启动，完成拼写和单选，确认不依赖开发服务器。
6. 从系统文件选择器导入题包，导出文本/JSON，通过系统分享保存到 App 外部。
7. 保存完整备份后，使用独立测试安装验证清除数据/卸载后的恢复。只在可丢弃测试数据上操作。
8. 使用相同签名覆盖安装新版本，确认原数据仍可读取；不同签名的 debug 构建不能代替升级验证。
9. 在浏览器与支持系统文本菜单的阅读器中长按单词，选择“拾词查词”；分别检查 App 冷启动、已打开和正在练习三种情况。
10. 不支持文本操作的 PDF 软件改用复制后主动粘贴；扫描版 PDF 不包含可直接选择的文字，初版无 OCR。

记录设备型号、Android 版本、键盘/阅读软件、步骤、预期与实际结果。
原生入口兼容性、文件分享和 WebView 数据保留必须在真实设备验证后才能宣称通过。

## 0.3 手机交互验收

新增纯规则/存储测试覆盖双向横滑阈值、返回弹层优先级与异步锁、JSON 限额/拒绝备份伪装、
v2 语境词备份恢复、听力索引与待绑定清单。浏览器流程验证双向退出和草稿恢复、控件和纵向滚动不退出、
写入失败拒绝退出、提交前没有查词按钮、提交后释义收藏、听力原文点词、导入位置与粘贴 JSON。

真实手机另验：Nothing 系统两侧边缘返回、收起软键盘后再次返回、横向拖播放器不退出、
分享/打开方式传入 JSON 冷启动和热启动、收到文件时练习不被打断、坏文件和超大文件不写库。
验证旧安装导出完整备份、相同签名升级后的记录，以及明确确认后的备份恢复；不要用清库修复。

## 1.0发布模式

开发演示回归由 `pnpm test:e2e` 构建带入口的测试界面；`pnpm test:release` 单独构建默认正式界面。
正式模式核对学习台/我的/听力均无示例载入入口、正常JSON导入与作答持久化，以及已有拓展错题可以继续练习返回。
Android发布流程另见 [RELEASE.md](RELEASE.md)。
