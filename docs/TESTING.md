## 本地检查

核心测试使用 Vitest + fake-indexeddb，覆盖协议校验、导入防覆盖、组合键、拼写规范化、复习间隔、
提前重复练习、幂等提交、草稿保留、备份恢复、无效备份保护、查词与生词去重。

浏览器测试使用 Playwright 的 Pixel 7 尺寸 Chromium，使用原生 File API 和下载事件验证：

- 导入示例、重复导入拒绝。
- 草稿跨刷新恢复、回车答题、连续练习、错题与选择题。
- 导出结果与完整备份，在全新浏览器上下文恢复。
- 首次资源缓存完成后的断网重开与作答。
- 查词、词形候选、自填生词与生词练习。

```bash
pnpm test
pnpm build
pnpm format:check
pnpm exec playwright install chromium
pnpm test:e2e
```

可通过 `PLAYWRIGHT_BROWSERS_PATH` 将测试浏览器放到指定目录。
测试服务只监听 127.0.0.1:4173。自动测试没有访问真实个人学习数据。
浏览器测试生成的截图和失败追踪用于审阅，不代表实际 Android 设备测试。

## Android 真机验收

本机尚无 Android SDK，未完成原生编译；工作流文件存在不等于 APK 已生成。
安装符合 Capacitor 8 要求的 Android Studio/SDK 后，先执行 `pnpm android:sync`。

1. 全新安装后无账户和学习记录，主动导入 JSON。
2. 在系统英文键盘与常用第三方键盘中，检查自动纠错关闭、回车提交、连续输入和键盘遮挡。
3. 输入一半后切后台、系统回收进程、重新进入，确认已成功保存的草稿恢复。
4. 答错与答对各一次，关闭重开后核对错题次数、原始答案和复习日期。
5. 飞行模式冷启动，完成拼写和单选，确认不依赖开发服务器。
6. 从系统文件选择器导入题包，导出文本/JSON，通过系统分享保存到 App 外部。
7. 保存完整备份后，使用独立测试安装验证清除数据/卸载后的恢复。只在可丢弃测试数据上操作。
8. 使用相同签名覆盖安装新版本，确认原数据仍可读取；不同签名的 debug 构建不能代替升级验证。
9. 在浏览器与支持系统文本菜单的阅读器中长按单词，选择“拾词查词”；分别检查 App 冷启动、已打开和正在练习三种情况。
10. 不支持文本操作的 PDF 软件改用复制后主动粘贴；扫描版 PDF 不包含可直接选择的文字，初版无 OCR。
