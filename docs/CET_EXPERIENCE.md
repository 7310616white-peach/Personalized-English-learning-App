# 四级题型体验（0.4）

学习台 → 打开四级题型体验 → 载入四级全题型体验，然后选一种题型。
示例入口保留。重复载入不会重置记录；听力首次点击时复用原来的原创体验库和四段 WAV。

## 本版材料

| 形式     | 本版体验                           |
| -------- | ---------------------------------- |
| 短篇新闻 | 一段原创合成录音，含选择与附加听写 |
| 长对话   | 一段原创合成录音，含选择与附加听写 |
| 听力篇章 | 一段原创合成录音，含选择与附加听写 |
| 仔细阅读 | 一篇原创文章、5道选择              |
| 选词填空 | 10空、15个备选词，每词用一次       |
| 信息匹配 | A–J段落、10条陈述，允许重复段落    |
| 汉译英   | 一段中文、英文输入、参考译文       |
| 短文写作 | 一篇题目、120–180词提示、参考范文  |

题型依据[中国教育考试网 CET-4 结构](https://cet.neea.edu.cn/html1/report/16123/196-1.htm)。
全部正文和参考答案为本项目原创，非历年真题；听力较短，未模拟完整试卷的题量、时长或正式分数。
听写是附加练习，不属于现行四级正式题型。
没有取得可核验、可公开分发的历年试卷，不能将原创材料标记成真题。
用户持有的真题可以在个人设备按相同格式导入；不要将无分发许可的试卷全文提交到开源仓库。

## 手机操作与保存

- 选词：阅读空号可以跳到对应选择框；已使用的词不可重复选择，清空原答案可释放该词。
- 匹配：先读段落，再给陈述选字母，同一字母允许多次使用。
- 作文/翻译：输入即存草稿，退出/刷新后可继续；字数为提示，不强制阻止短文提交。
- 练习页空白处左右横滑均保存退出，输入框和选择框不抢手势。
- 提交前隐藏参考答案和查词入口；提交成功后才显示解析、参考材料和原位查词。
- 客观题空答按错误计；选词/匹配按整篇记录复习进度，结果保留逐题答案。
- 作文/翻译保持待批改，不与范文逐字比较、不生成伪分数、不自动安排“答错”复习。
- 题包与数据 → 导出文本/JSON，包含题目、原文、选项、全部作答与参考，交给每日英语批改。

## v3 每日题包

兼容旧 v1/v2。v3 在 v2 字段上增加必填 `written` 数组，没有拓展任务则为空数组。
可直接参考 [完整原创示例](../public/examples/cet4-formats.json)。单个题包文件仍限10 MB。
题目与选项/段落 ID 唯一；答案引用有效ID；选词原文每空对应一个 `[[q1]]` 标记。
所有任务有 `id/type/title/instructions/source`，不在旧 choice 对象里任意塞字段。

| type        | 额外字段                                                                   |
| ----------- | -------------------------------------------------------------------------- |
| word-bank   | passage、options:[{id,text}]、questions:[{id,prompt,answerId,explanation}] |
| matching    | paragraphs:[{id,text}]、questions:[{id,prompt,answerId,explanation}]       |
| translation | prompt、reference、explanation                                             |
| writing     | prompt、reference、explanation、minWords、maxWords                         |

导入的新拓展任务在学习台“题型体验”列表内显示。App 中的可复制首次设置和每日提示词已升级 v3。
真实真题的 source 应记录年份/月份/套次与来源；AI 生成内容应标原创仿真。
当前客观题按给定参考判分，生成题的答案仍应核对。

## 数据边界

同一数据库原地升级到 schema 3，只新增 writtenAttempts、writtenDrafts、writtenProgress，保留原表与库名。
作答与进度、草稿清理在同一事务；失败不显示提交结果。重复提交使用稳定 UUID 去重，过时题面拒绝写入。
只清理与所交答案完全相同的草稿，避免覆盖另一窗口的更新。
备份 v3 带全部拓展记录，支持 JSON/带音频 ZIP；旧 v1/v2 备份仍可明确确认恢复。
恢复前验证题包、引用与重新计算的客观评分；旧版 App 不认识 v3 备份，请使用新版恢复。
