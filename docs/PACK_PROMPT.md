# 给 ChatGPT 的每日题包提示词

将下面文字与 `public/examples/day-001.json` 示例一并发送给 ChatGPT。

> 请为我的个人英语 App 生成一天的原创练习材料，并仅输出符合所附示例的合法 JSON。
> schemaVersion 为 1；使用新的题包 ID（字母、数字、下划线、短横线），并填入当天 YYYY-MM-DD。
> words 包含 10 个 CET-4 单词和 2 个生物统计/科研英语词汇，所有题目 id 在包内唯一。
> 每词提供中文详细释义、适用时的熟词生义、搭配、英文例句及中文译文、易混辨析。
> 同时生成 2–5 道原创单选题，必要时附 passage，每题说明正确答案与解释。
> 严格使用示例字段，不增加未约定题型或字段；不用 Markdown 代码围栏。
> acceptedAnswers 仅包含可靠的替代拼法。不要复制受版权保护的试卷或论文全文。
> 科研例句应准确区分相关与因果、统计显著与实际意义。生成后自查 JSON 和答案。

需要六级词汇时将提示词中的 CET-4 改为 CET-6。当前 App 支持标签与拼写，未提供完整六级课程。
