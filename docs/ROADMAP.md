# 逐步开发计划

每一步在数据协议、测试和手机体验稳定后再扩展，避免同时维护多个未完成系统。

| 阶段               | 范围                                                     | 进入下一步的条件                                     |
| ------------------ | -------------------------------------------------------- | ---------------------------------------------------- |
| 0.1 Web MVP        | 拼写、单选、题包导入、复习、错题、导出备份、基础查词     | 核心事务与文件往返通过，手机尺寸与离线浏览器测试通过 |
| 0.2 Android 试用   | APK、软键盘、文件选择/分享、系统选词、升级保留记录       | M1 构建成功，实际 Android 设备完成验收和备份恢复     |
| 0.3 英语题型       | 翻译、作文输入、范文与句型、待人工批改结果               | 草稿和长文本导出可靠，题包升级可兼容已有数据         |
| 0.4 练题与科研阅读 | 选词填空、信息匹配、听力音频、论文摘要练习               | 独立题型测试、资源许可、音频离线与体积策略完成       |
| 后续评估           | 更完整且许可明确的离线词典、词形库、复习算法改进、SQLite | 有真实使用反馈再决定；数据迁移先验证                 |

AI 接口仅预留模块边界，不实现调用、账户连接或 API 密钥配置。
生词查阅优先低成本；大词库引入前评估许可、包体积和设备查询性能。
